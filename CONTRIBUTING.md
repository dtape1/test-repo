# Як зробити внесок

1. Зробіть fork репозиторію test-repo
2. Створіть нову гілку: git checkout -b update-readme
3. Внесіть зміни у файли та перевірте, що git status показує коректні зміни
4. Закомітьте зі зрозумілим повідомленням: git commit -m "Update README with setup instructions"
5. Відкрийте Pull Request з описом того, що саме змінено і чому
