# Кодекс поведінки

Ми прагнемо дружньої та відкритої спільноти. Учасники зобов'язані:

- ставитись з повагою до інших, незалежно від досвіду чи поглядів
- уникати образ, дискримінації та особистих нападок
- конструктивно приймати та надавати критику

Порушення можна повідомити через Issues репозиторію.
